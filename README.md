
# Recipe Assistant

## Overview

Recipe Assistant is an intelligent cooking app designed to help users find and follow recipes efficiently. It supports adding to favourites, ingredient-based searches, and sorting and filtering by preparation time and difficulty. The assistant provides step-by-step cooking instructions and allows users to export recipes to PDF for convenience. Moreover, with the power of artificial intelligence, users can navigate the app effortlessly without touching the keyboard—keeping their devices clean.

## Features

- **Smart Recipe Search**: Find recipes based on available ingredients, preparation time, and difficulty level.  
- **Large Recipe Database**: Access a database with at least 1,000 recipes.  
- **Step-by-Step Guidance**: Follow easy-to-understand cooking instructions in an interactive format.  
- **Export to PDF**: Save and print recipes in a convenient PDF format.  
- **Gesture Control**: Navigate the interface using gestures.
